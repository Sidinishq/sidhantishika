# Sidhant & Ishika – Groom-side Wedding Invite (#SidInIshq)

Single-file site: index.html contains everything (photos, door, music are built in).

## Publish on GitHub Pages (new repository)
1. github.com → "+" → New repository → name it (e.g. sidhant-ishika-groom) → Public → Create.
2. Click "uploading an existing file" → drag in index.html (and this README) → Commit changes.
3. Settings → Pages → Source: Deploy from a branch → Branch: main, folder: / (root) → Save.
4. Wait 1–2 minutes. Link: https://USERNAME.github.io/REPO-NAME/

## Editing later
All text lives in the CONFIG block near the top of index.html (names, events, contacts, dress code).
